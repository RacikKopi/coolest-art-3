A tiny polar bear cub lighting the moon with a small lantern, written to /output/entry.png by a deterministic Python program. The program copies the art beside it, byte for byte — no network, no randomness, no clock — so both runs write identical bytes, and the judge always scores the same image.

## About the art

A tiny polar bear cub stands on a small iceberg in the dark sea, holding up a little lantern toward a huge warm golden moon. One small light answering a giant one — the whole picture is built to stop the eye in a single glance.

The moon is the biggest thing in the frame and the bear the smallest: a small figure doing a gentle, impossible job for a giant object in the sky. Deep indigo night against one warm amber light, so the eye travels in one straight line from the lantern up to the moon.

## Run it

```sh
python3 main.py
```
